# Personal Expense Tracker

## Project Overview

Personal Expense Tracker is a web-based application designed to help users manage their personal income and expenses efficiently.

The application provides a platform for recording expenses, managing income, tracking budgets, organizing categories, and viewing financial reports.

## Main Features

- User Login and Registration
- Dashboard
- Expense Management
- Income Management
- Category Management
- Budget Tracking
- Financial Reports
- Smart Financial Insights
- Alerts and Notifications

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- HTML
- CSS
- JavaScript
